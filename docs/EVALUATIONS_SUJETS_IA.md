# Évaluations, sujets IA et variantes\n\n## Principe\n\nUne évaluation représente l'épreuve à organiser. Les sujets concrets sont des variantes de cette même évaluation.\n\nExemple : une composition de mathématiques en 3e A peut avoir les variantes A, B, C et D. Elles évaluent les mêmes objectifs et unités du programme avec un niveau, un barème et une structure comparables, mais des énoncés/données différents.\n\n## Création\n\nL'enseignant ne peut créer une évaluation que pour une affectation pédagogique officielle (`teacher_assignments`).\n\nDeux modes :\n- **EduSoft IA** : génération de plusieurs variantes et de leurs corrigés séparés.\n- **Import PDF** : conservation du fichier original comme sujet importé.\n\nLe sujet est rattaché aux unités du programme réellement enseignées via `assessment_subjects`. Le programme n'est jamais copié dans le sujet.\n\n## Workflow\n\nEnseignant → brouillon → soumission → responsable de matière / vérification pédagogique → Directeur des Études ou personne habilitée → validation → programmation → publication/passation → correction → résultats → moyennes → bulletins.\n\nLe serveur contrôle les transitions avec `transition_assessment_workflow`. L'interface ne constitue pas une autorisation.\n\n## Variantes anti-triche\n\n`assessment_variants` contient les différentes versions d'une même évaluation.\n\n`assessment_variant_assignments` associe ensuite une variante à chaque élève.\n\nLa fonction `distribute_assessment_variants` réalise une répartition aléatoire équilibrée entre les variantes après validation de l'évaluation. Une nouvelle répartition remplace la précédente pour éviter les doublons d'affectation.\n\n## IA\n\nLa fonction Supabase `edusoft-ai-assessment` génère uniquement à partir du contexte pédagogique fourni par EduSoft : classe, matière, type d'évaluation, barème, durée, programme et unités sélectionnées.\n\nL'IA ne valide jamais officiellement le sujet.\n\n## PDF\n\nLes PDF sont conservés dans le bucket privé `assessment-subjects`, dans un chemin isolé par école et évaluation. L'application utilise des URLs signées pour l'ouverture.\n\n## Sécurité\n\n- isolation par école ;\n- année scolaire ;\n- affectation enseignant-classe-matière ;\n- RLS ;\n- workflow serveur ;\n- corrigé séparé du sujet ;\n- aucune publication automatique par l'IA.
