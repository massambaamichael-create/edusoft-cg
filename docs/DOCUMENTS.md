## 1. Service transversal Documents

```
Document
 ↓
Création
 ↓
Validation
 ↓
Signature
 ↓
Cachet
 ↓
Publication
 ↓
Archivage
```

Types : certificats, attestations, bulletins, relevés, convocations, reçus, factures, rapports, procès-verbaux, courriers, documents administratifs.

## 2. Signatures et cachets

### Mode numérique
Selon exigences juridiques applicables :
- Signature électronique
- Cachet électronique
- Identité du signataire
- Date
- Référence
- QR Code de vérification

### Mode papier
Document généré avec zones réservées → téléchargement → impression → signature / cachet manuels → scan → réimport → archivage dans EduSoft.

## 3. QR Code de vérification

Les documents importants possèdent :
- Numéro unique
- QR Code
- Identifiant
- Statut

La vérification publique ne révèle que les informations nécessaires à l’authentification du document.
